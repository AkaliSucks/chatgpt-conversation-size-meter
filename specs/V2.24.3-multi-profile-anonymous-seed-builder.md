============================================================

Do not treat exported samples as calibration automatically.

Export is manual/read-only.

============================================================
6. SEED PROFILE BUILDER TEST UTILITY
============================================================

Add a test/helper utility that accepts a list of anonymous samples and
produces candidate seed profiles grouped by exact:

model + canonicalEffort

Rules:

- MAX samples only establish MAX frontier candidates.
- Collapse repeated samples from the same supplied logical observation
  when a caller supplies an explicit anonymous group key in tests.
- Do not manufacture independence from duplicate vectors.
- Preserve heterogeneous vectors.
- Text frontier = maximum valid MAX displayLikeTokens.
- State frontier = maximum valid MAX activeBranchBytes.
- Retain the contributing anonymous vectors rather than reducing the
  entire seed to only two scalar anchors.
- Success samples are diagnostic/bracketing evidence only and do not
  become MAX profiles.

This helper may be test/dev-only if exposing it in production is not
necessary.
