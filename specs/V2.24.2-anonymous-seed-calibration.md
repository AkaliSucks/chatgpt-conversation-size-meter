GOAL
====
Make the pressure indicator useful immediately on a fresh installation
without requiring that user to first accumulate personal MAX events.

Add a small READ-ONLY bundled anonymous calibration seed.

This must preserve the empirical/non-official nature of the pressure
indicator.

============================================================

- real conversation IDs
- chat titles
- timestamps
- prompt text
- response text
- URLs
- account/user IDs
- attempt IDs
- MAX episode IDs
- screenshots
- raw mappings
- raw diagnostics

============================================================

CALIBRATING

Do not silently fall back across unrelated model families.

============================================================
4. DUAL-AXIS FRONTIER
============================================================

Preserve the V2.24.1 dual-axis algorithm.

Seed text frontier:
maximum anonymous seed displayLikeTokens contribution

Seed state frontier:
maximum anonymous seed activeBranchBytes contribution

Do not hard-code a single fake context limit.

When both bundled and local evidence exist:

textAnchor =
    max(seedTextFrontier, validLocalTextFrontier)

stateAnchor =
    max(seedStateFrontier, validLocalStateFrontier)

This first seeded revision should allow local evidence to EXTEND a
frontier upward but should not allow one sparse local observation to
collapse the anonymous seed frontier downward.

Document this limitation.

Pressure remains:

textRatio = current displayLikeTokens / textAnchor
stateRatio = current activeBranchBytes / stateAnchor

combinedRatio = max(textRatio, stateRatio)

score = rounded/clamped integer 0..99

Only verified CURRENT MAX displays PRESSURE MAX.

============================================================
5. CONFIDENCE
============================================================

Bundled seed alone must remain LOW confidence.

Do NOT treat three bundled anonymous profiles as three locally verified
conversations for confidence.

Expose separately:

seedMaxProfileCount
localIndependentMaxConversationCount

For this revision it is acceptable to keep overall confidence LOW
unless existing local confidence rules independently justify more.

Do not increase confidence merely because bundled data exists.
